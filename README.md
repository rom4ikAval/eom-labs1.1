Lab 1. Представлення даних у пам'яті комп'ютера

1. Мета роботи
Мета лабораторної роботи — експериментально дослідити, як комп'ютер представляє різні типи даних у пам'яті.

Під час роботи ви перевірите:

скільки пам'яті займають основні типи C;
як числа представляються у десятковій, шістнадцятковій та двійковій формах;
як одна й та сама послідовність бітів може мати різну інтерпретацію;
як представляються знакові та беззнакові числа;
що відбувається на межах діапазону беззнакового типу;
як символи представляються числовими кодами;
як багатобайтові значення розташовуються у пам'яті;
який порядок байтів (endianness) використовує система.

Головне питання лабораторної:

Що насправді знаходиться в пам'яті комп'ютера, коли програма працює з числом або символом?

досліджувати окремі байти значення у пам'яті;

6. Завдання 3. Виведення бітів
Тепер зробимо двійкове представлення видимим безпосередньо у програмі.

Створіть функцію:

void print_binary(unsigned char value)
яка виводить усі 8 бітів значення.

Для отримання окремого біта можна використати:

(value >> i) & 1
Наприклад:

#include <stdio.h>

void print_binary(unsigned char value)
{
    for (int i = 7; i >= 0; i--) {
        printf("%u", (value >> i) & 1u);
    }
}

int main(void)
{
    unsigned char value = 65;

    printf("Decimal: %u\n", value);
    printf("Hex:     0x%02X\n", value);
    printf("Binary:  ");

    print_binary(value);

    printf("\n");

    return 0;
}
Очікуваний результат:

Decimal: 65
Hex:     0x41
Binary:  01000001
Перевірте значення:

Поясніть

#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint32_t value = 0x12345678;

    printf("byte 1 = 0x%02X\n", p[1]);
    printf("byte 2 = 0x%02X\n", p[2]);

}

11. Завдання 8. Визначення Endianness
На основі попереднього експерименту визначте, яку організацію байтів використовує система:

Big-endian
чи

Little-endian
Для little-endian:

value = 0x12345678

Lower address
    ↓

+--------+
|   78   |
+--------+
|   56   |
+--------+
|   34   |
+--------+
|   12   |
+--------+

    ↑
Higher address
Модифікуйте програму так, щоб вона виводила не тільки значення байта, а й адресу кожного байта.

Для адреси використовуйте:

printf("%p", (void *)&p[i]);
Отримайте приблизно:

Address             Value
0x7ff...             78
0x7ff...             56
0x7ff...             34
0x7ff...             12
Питання
У якому напрямку змінюються адреси?
Який байт знаходиться за найменшою адресою?
Чому це свідчить про little-endian?
Чи змінилося саме число 0x12345678, чи змінився лише порядок його байтів у пам'яті?
